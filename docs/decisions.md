# 製品ルール

- 画面全体で「ライブ（暫定）」「確定処理中」「確定済み」を区別し、行ごとの確定印は付けない。[ライブ](live.md)
- 画面とテキスト書き出しは同じ発話を使う。空本文と討論中の背景のみの発話を除き、低優先度の発話は含める。[書き出し](export.md)
- 認識不能は ASR の構造化状態で扱い、特定の文字列を理由に本文を隠さない。イベントには空本文を含む全区間を残し、公開 JSON は空本文を除く。[保存形式](storage.md)
- 話者分離前は話者見出しを出さない。分離後は重なる話者時間の 80% 以上を占める話者を採用し、満たさない場合は併記する。該当 span がなければ UNKNOWN。[確定処理](final.md)
- 話者ラベルは Speaker 1–7、OTHER、UNKNOWN。同じ確定 run 内の番号は固定し、再処理では振り直してよい。[確定処理](final.md)
- テキスト書き出しは本文の改行を空白にして 1 行 1 発話とする。[書き出し](export.md)
- Jev が confidence 0.90 以上で LOW_PRIORITY とした発話は内容を問わず折り畳む。「低優先度」のラベルを付け、展開すれば原文を読める。[Jev](jev.md)・[ライブ](live.md)
- 録音中も ASR 本文が保存され次第 Jev へ渡す。行は Jev の判定が届くまで表示せず（折り畳み対象は最初から折り畳んで表示し、後から折り畳み直さない）、時間順を保つ。Jev 無効・失敗・保留・停止の行は即時に通常表示する。ASR drain は Jev を待たない。Jev の失敗は録音やライブ ASR を止めない。[ライブ](live.md)・[Jev](jev.md)
- 停止時にライブ Jev を取り消す。確定処理は全音声を新しい区間・本文で認識し、前後の空白・改行を trim した確定本文と完全一致する同一セッションの保存済みライブ判定だけを再送せず引き継ぐ。元 run・segmentation run・segment を記録し、確定本文を使う。[確定処理](final.md)・[保存形式](storage.md)
- 通常行は矢印のない平文で、詳細は時刻ボタンの popover に出す。同じ話者の連続行は狭く、話者見出しの前は広く空ける。[ライブ](live.md)
- ライブ認識は閉じた VAD 区間または 14 秒分割単位。長い発話の初表示は区間が閉じるまで遅れる。分割の端数 continuation も保持する。[ライブ](live.md)
- critical の間はライブ認識を止め、録音を続ける。冷却後は滞留分の最古から再開し、確定処理で全体を認識する。[ライブ](live.md)
- 「最新へ戻る」は末尾へ移動する。自動追従は利用者のスクロール操作でのみ解除する。非同期操作には実行中表示と重複防止を設ける。[ライブ](live.md)
- 録音も確定処理もない待機中は ASR・話者分離のモデルと MLX キャッシュを解放し、次の録音・確定処理で読み込み直す。読み込み中のライブ表示の遅れは許容する。[アーキテクチャ](architecture.md)
- 内部音声は録音・import とも **16 kHz mono float32 PCM**。全入力 channel の平均後、保存前の ingress で一度だけ連続 SRC を行う。VAD・ASR・話者分離は同じ canonical 音声を直接読む。必要容量は実保存形式で計算し、開始時に空き容量を取得できなければ録音しない。[音声入力](capture.md)・[保存形式](storage.md)
- 録音の書き出しは保存済みの 16-bit FLAC `recording.flac` の無変換コピー。FLAC 化前の録音は書き出せない。読み込み音声は保存済み original の無再圧縮コピー。書き出しフォルダーは保存済みセッションの実フォルダー名をそのまま使い、日時・stem・ID から再計算しない。[書き出し](export.md)
- 入力音量調整は既定入力デバイスが変わったら ownership を放棄し、停止時に旧デバイスの音量を戻さない。[音声入力](capture.md)
- 入力音量を変更できない機器は橙色の非致命な注意。音量の注意と VAD による監視不能は別状態・別表示とする。[音声入力](capture.md)
- 録音保存エラーは原因別の日本語で報告し、破損 chunk 名などの識別情報を保つ。入力停止はマイク・システム音声に応じた文言で伝える。[音声入力](capture.md)
- writer 障害でも健全な checkpoint 範囲を確定処理へ送り、録音障害の表示は残す。書き出し・録音開始の後始末失敗は元のエラーと併記する。[音声入力](capture.md)・[書き出し](export.md)
- 停止後、読み込み、再処理、クラッシュ復旧は同じ確定パイプラインを使う。全段階が成功してから run を一括公開し、失敗・一時停止では直前の正常表示を保持する。[確定処理](final.md)
- 確定処理と読み込みは critical で paused として保持する。アプリは冷却後に再開し、CLI は明示的な再開操作を使う。[確定処理](final.md)
- 復旧は確定 run の全量再実行。途中失敗した run も取得済み ASR 計測値を保持する。[確定処理](final.md)
- 派生 metadata の破損は明示し、原音声が無傷なら再処理を許可する。読めない metadata の置換は利用者による明示的な再処理に限る。[確定処理](final.md)・[書き出し](export.md)
- 話者 span が負または音声範囲外なら明示エラー。話者間の gap は中点で分割し、独立した UNKNOWN gap 行は作らない。[確定処理](final.md)
- 確定処理の来歴は run ごとに実際のエンジン・モデル・version・設定を保存し、再処理時に古い run の来歴を流用しない。ライブの認識完了イベントは実エンジンとモデルを保存する。永続 timeline は sample rate・channels・encoding を自ら記述する。[保存形式](storage.md)
- セッション保存フォルダーは作成時のローカル日時・録音または元ファイル名 stem・UUID 小文字先頭 8 桁。identity は manifest の完全 UUID、読み取りは実 URL と明示検証を使い、名前を再計算しない。欠損・不正・重複 ID はフォルダーごとのエラーとして残し、保存済み一覧は URL で選択する。[保存形式](storage.md)
- セッション root の既定値を使うのは GUI のみ。セッションを作成・検索する CLI は各モードで安全性検証済みの `--sessions-root` を必須とする。artifact-only 評価 CLI は保存済みセッションを検索しないため root を要求しない。[保存形式](storage.md)・[検証](testing.md)
- 場面判定は音響のみ。手がかりのない冒頭は講義。Jev はアプリで優先度分類にだけ使い、CLI では無効。[Jev](jev.md)
- 近接度は音響範囲の判定専用で、話者ごとの固定 profile とする。[Jev](jev.md)
- Jev の 401/403 はバッチを止めて「API キーの修正が必要」を伝える。利用量が不明な成功は token 数不明として数える。[Jev](jev.md)
- ライブ遅延は現行の閉 VAD 経路の「発話終了から最初の非空更新」から測る。[ライブ](live.md)・[検証](testing.md)
- 注釈を前提とする誤除外・場面転換時刻の評価は行わない。参照文のある ASR CER と場面振動数を評価する。[検証](testing.md)
- Linux の話者判定は 7 人登録前でも曖昧帯を UNKNOWN とし、最初の十分な clean 発話で登場順を数える。部分重なりは十分な非重複 subspan から embedding を得る。[Linux 評価](linux.md)
- VOICEVOX の 10 話者 corpus は異なる人物 identity を選び、engine・query・音声 hash を保存する。配置係数と実重複率を分離し、DER 正解は実発話 activity とする。[Linux 評価](linux.md)
- 自然会話の CER は verbatim を主、content を補助とする。cold load・warm 推論・常駐メモリを分け、baseline に再現条件を含める。cache の SHA 不一致は即失敗。[Linux 評価](linux.md)
- Linux ASR artifact は CER 用に全音声を 1 segment とし、run 計測は recording_id と completed・failed・paused を使う。メモリ取得失敗は値なしと理由を記録する。[Linux 評価](linux.md)・[検証](testing.md)
