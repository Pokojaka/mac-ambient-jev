# 参照文のフィラー・言い直しの印の精度（2026-11-14）

CER は参照文の `(F …)` と `(D …)` を任意文字として扱う（[decisions](../decisions.md)）。自分の録音の参照文は、音声認識モデルではない LLM が文字だけを見て印を付ける。この記録は、どのモデルで、どの手順で印を付けるかを決めるために測った値である。

## 結果と判定

- 1 つのモデルで 1 回印を付けるだけでは、付け漏れが印なし文字の 0.4〜0.9% 残る。
- 自分の録音の参照文は次の手順で作る。fable と opus が別々に印を付け、両方の印の和集合を取る。2 つの印が食い違う部分は、どちらの印かを伏せて fable が裁定する。

| 印を付けたもの | 付けすぎ | 付け漏れ |
| --- | ---: | ---: |
| opus（2026-10 に作った既存の正解） | 0.11〜0.14% | 0.43〜0.45% |
| fable（`claude-fable-5-2`） | 0.01〜0.03% | 0.88〜0.90% |
| opus と fable の和集合 | 0.14〜0.15% | 0%（見かけの値。下の限界を参照） |

- 値は、印なし正解文字数（約 45,780 字）に対する文字数の比。句読点と空白は数えない。
- 幅は 2 回の裁定（下記）の間の差。
- 付けすぎた印は、ASR が実際の内容を落としてもその文字を誤りに数えない。付け漏れは、フィラーを書かない ASR の削除を誤りに数える。

## 入力

- 講義の ASR 文（製品の Qwen3-ASR 8bit の出力）69 区間、約 53,800 字。
- 正解の初期値は、2026-10 に opus が講義の文字起こしラベル付け指針で付けた `(F …)`（3,948 字）と `(D …)`（688 字）。
- 名大会話コーパスの既存ラベルは Sonnet と sol が付けたもので、人手の正解ではないため使わなかった。CSJ は利用条件により使わなかった。

## 手順

1. opus の正解から印を外した本文を fable に渡し、同じ指針で印を付けさせた。fable には opus の印を見せていない。
2. 2 つの印が食い違う 236 か所を抜き出した。前後 40 字の文脈を付け、どちらの印かを伏せて、別の fable に判定させた（印を付ける / 付けない / 一部 / 文字だけでは決められない）。
3. 裁定の偏りを確かめるため、2 回目の裁定には対照を混ぜた。両方が印を付けなかった「その」「まあ」「もう」などの 60 か所と、両方が付けた 30 か所である。
4. 正解を「両方が一致した文字 + 裁定結果」として作り直し、各モデルを採点した。「決められない」と判定された 12〜16 字は採点から除いた。

## 裁定の信頼性

| | 印を付ける | 付けない | 一部 | 決められない |
| --- | ---: | ---: | ---: | ---: |
| 対照：両方が付けなかった 60 か所 | 2 | 57 | 0 | 1 |
| 対照：両方が付けた 30 か所 | 30 | 0 | 0 | 0 |
| fable だけが付けた 61 か所 | 56 | 1 | 4 | 0 |
| opus だけが付けた 175 か所 | 151 | 14 | 2 | 8 |

- 1 回目と 2 回目の裁定は、236 か所のうち 221 か所で一致した。
- fable だけが付けた印も opus だけが付けた印も、大半は正しかった。両方とも付け漏れが主な誤りである。opus の誤りは、強調の「もう」をフィラーとしたものなど。

## 限界

- 正解は、2 つのモデルがどちらも印を付けなかった箇所を検証していない。和集合の付け漏れ 0% は、その分を数えられない見かけの値である。
- 裁定役も LLM で、人手の正解ではない。対照での誤判定は 90 か所中 2 か所だった。
- 入力は ASR の文で、誤認識や句読点の崩れを含む。実際の参照文の元になる Gemini の逐語書き起こしとは分布が違う。
- 文字だけでは指示語かフィラーかを決められない「この」「こう」が残る。
