## 字幕 API

`youtube-transcript-api` 1.2.4 で動画 `T-jKleBEeM4` の日本語作成者字幕を取得した。`is_generated=false`、506件で、各件の text・start・duration を保存した。開始・継続時間はミリ秒精度。元の XML と JSON3 も取得して照合した。API の返す情報と方法は[ライブラリの資料](https://github.com/jdepoix/youtube-transcript-api)に対応する。YouTube Data API の認証付き `captions.download` を使った測定ではない。

元字幕の話者略号は `水/` と `堀/`。151件が先頭から末尾まで一人の話者表記、353件が両話者を含む。残りは話者表記のないタイトル1件と、先頭の話者表記が抜けた1件（caption index 68）。index 68 は文頭が「潜性遺伝子・潜性遺伝子の組合わせの方が多くなって」、後半に `堀/うんうん。` がある。この字幕全体を堀の発話として採点しない。話者表記のない部分の人物を予測結果から補っていない。

JSON3 でも1字幕内のテキストは単一 `utf8` segment で、話者交代ごとの時刻は入っていなかった。

## 単独話者区間の一致率

字幕の開始時刻に固定 offset 7.88秒を加えて録音時刻へ移した。offset は冒頭タイトルの音声・文字時刻合わせから求め、話者予測を使って最適化していない。タイトルの先頭は動画2.499秒、録音10.379秒。末尾基準の offset は7.78秒で、字幕と音声境界が完全一致するわけではない。

各単独話者字幕の先頭・末尾0.25秒を除き、残りの全時間を評価した。話者番号の入れ替えを誤りにしないよう、全対象に対して一対一対応を一度決めた。Speaker 1 は `水`、Speaker 2 は `堀` となった。区間ごとに都合よく対応を入れ替えていない。

予測で同じ話者だけが active な時間を正解、別話者・複数話者は取り違え、active な話者がなければ検出漏れとした。字幕単位の正解・不正解の件数ではなく、時間による集計である。

| 参照話者 | 正解時間 | 取り違え時間 | 検出漏れ時間 | 一致率 |
| --- | ---: | ---: | ---: | ---: |
| Speaker 1（水） | 494.273063秒 | 2.239562秒 | 0.877375秒 | 99.3733% |
| Speaker 2（堀） | 251.247875秒 | 16.208375秒 | 2.925750秒 | 92.9233% |
| 合計 | 745.520938秒 | 18.447937秒 | 3.803125秒 | 97.1019% |

時刻の不確かさを調べるため、同じ両端0.25秒除外のまま offset を動かした。-0.25秒で95.9140%、+0.25秒で97.4912%、±0.5秒まで含めると94.3605–97.4912%。字幕の境界誤差が値に影響する。最も良かった offset を主結果に選んでいない。境界除外なし・0.5秒除外の結果も保存 JSON に含めた。

## 混在字幕を含む全編の推定 DER

[Qwen3-ForcedAligner](https://huggingface.co/Qwen/Qwen3-ForcedAligner-0.6B)の日本語時刻合わせをローカルで実行した。評価用モデルは `mlx-community/Qwen3-ForcedAligner-0.6B-8bit`、revision `0e1a68e91d815300c7c9754b2a7639378b23db15`。録音音声を外部 API へ送っていない。

全506字幕を本文30秒以内の92まとまりにし、前後1字幕を音声と本文の文脈に含めて時刻合わせした。採点用には各字幕を一度ずつ取り出す。NFKC 後に話者略号を除き、予測された単語の文字列を入力本文と照合してから、その文字範囲に元字幕の話者を対応させた。別話者・別字幕をまたぐ曖昧な単語対応や、音声切り出し範囲を超えた対象単語はエラーとした。

11,891単語のうち10,842単語に正の長さがあり、1,049単語は長さ0だった。連続する同じ話者表記の発話ごとに、最初と最後の正の長さの単語から参照区間を作った。全989発話表記のうち44発話は全単語が長さ0で、時間のある参照を作れていない。人物名のない2発話は評価時間から除き、正の長さの話者付き参照は943区間。字幕の話者を音声から独立に使える一方、短い相づちや同時発話の正確な時間を保証できない。

動画全編の時刻範囲から無ラベルの2区間（タイトル1.28秒、index 68の文頭3.44秒）を除いた2528.041秒を評価領域とした。参照の重なりは話者時間を重複計数するため、下記の分母は評価領域の長さとは異なる。本リポジトリの `StandardDiarizationEvaluator` を最適化ビルドした helper で評価し、話者ラベルの一対一対応は全体で最適化する。

| 境界除外 | 参照話者時間 | 取り違え | 検出漏れ | 誤検出 | DER |
| --- | ---: | ---: | ---: | ---: | ---: |
| なし | 2416.866秒 | 202.791秒 | 13.598秒 | 85.824秒 | 12.5043% |
| 前後0.25秒 | 1993.811秒 | 87.264秒 | 6.854秒 | 5.157秒 | 4.9792% |

DER は `(取り違え + 検出漏れ + 誤検出) / 参照話者時間`。`1 - DER` を話者の正解率として表示しない。自動時刻合わせによる短い相づちの消失、ほぼ単調な時刻推定による同時発話の不足、字幕の省略・編集が残るため、全編の人手正解 DER と同等には扱わない。
